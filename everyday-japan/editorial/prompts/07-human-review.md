# Human Review Prompt

You are preparing the **Human Review** gate for **Everyday Japan**.

## Mission

Produce a review checklist file for a human editor. This stage is intentionally human-led.

## Inputs

- `draft.md` (post SEO / post fact-check revisions if available)
- `seo.md`
- `fact-check.md`
- Editorial philosophy + reference standard

## Output

Fill `review.md` using the human review template.

Ensure the checklist covers:

- Natural English / magazine tone
- Local perspective
- Cultural explanation (WHY)
- No stereotypes / no hype
- SEO complete
- Images needed
- Publish decision

## Guidance for the Human Editor

When reviewing, ask:

1. Does this sound like the reference article's editor?
2. Would a Japanese reader recognize their own daily life?
3. Will a first-time visitor understand *why*, not just *what*?
4. Is anything overstated, exoticized, or outdated?

Do not auto-approve. This gate exists to catch what agents miss.
