# Publish Checklist

- [ ] Human review approved
- [ ] Fact-check verdict is pass (or revisions applied)
- [ ] SEO title, meta description, slug, tags finalized
- [ ] Internal links valid
- [ ] Schema JSON reviewed
- [ ] Images + alt text ready (or explicitly deferred)
- [ ] Final file written to `content/articles/<slug>.mdx`
- [ ] Draft folder retained for audit (recommended)
- [ ] Related articles updated if needed
