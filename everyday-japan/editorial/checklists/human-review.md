# Human Review Checklist

Use with `review.md` for each article.

## Voice & Perspective

- [ ] Sounds natural
- [ ] Local perspective
- [ ] Cultural explanation (WHY)
- [ ] No stereotypes
- [ ] No "Japan is amazing" tone
- [ ] Balanced / factual
- [ ] Matches reference article standard

## Structure

- [ ] Hook
- [ ] The Question
- [ ] Local Perspective
- [ ] Cultural Background
- [ ] Real-life Examples
- [ ] Visitor Tips
- [ ] FAQ
- [ ] Closing Insight

## Packaging

- [ ] SEO complete
- [ ] Fact check addressed
- [ ] Images needed (listed)
- [ ] Frontmatter complete

## Decision

- [ ] Revisions requested
- [ ] Approve for publish
- [ ] Publish
