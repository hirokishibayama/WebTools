# Templates

Empty Markdown skeletons copied into `content/drafts/<slug>/` when a new article starts.

| Template | Stage artifact |
|----------|----------------|
| `topic.md` | `topic.md` |
| `research.md` | `research.md` |
| `outline.md` | `outline.md` |
| `article.md` | `draft.md` |
| `seo.md` | `seo.md` |
| `fact-check.md` | `fact-check.md` |
| `review.md` | `review.md` |

Placeholders: `{{TITLE}}`, `{{SLUG}}`, `{{DATE}}`, `{{AGENT_OR_HUMAN}}`.
